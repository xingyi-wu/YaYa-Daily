# YaYa Daily · 芽芽日常

A simple time management app. Available in Chinese and English.

**Version:** 0.6.4 · Android

**Features:** Schedules · Timeline · Four-Quadrant Tasks · Focus Time · Sleep Recording · Offline · Backup
